## Svod RAG - Kwork listing draft (Round 4)

### Title
RAG-ассистент для вашей базы знаний: загрузка документов + ответы с источниками

### Short description
Сделаю рабочий RAG-сервис под ваши документы (PDF/TXT/MD): загрузка файлов, запросы на русском, ответ с цитатами источников. Покажу живое демо с полным циклом.

### Full description
Что получите:
- Веб-демо с интерфейсом: загрузка документов, поле вопроса, блок ответа и источников
- API-эндпоинты для интеграции: `/api/upload`, `/api/query`, `/api/stats`
- Ответы с указанием, из какого фрагмента документа взята информация
- Базовая защита API-ключом и готовность к деплою

Как проходит демонстрация:
1. Загружаем тестовый файл через UI
2. Делаем вопрос в UI или через API
3. Получаем ответ + список источников

Подходит для:
- HR-баз знаний
- Внутренних FAQ
- Поддержки и регламентов
